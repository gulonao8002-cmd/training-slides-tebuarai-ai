# 手足のついたAI — 第2回AI研修スライド

税理士法人ファインブレーン 第2回AI研修（2026年10月7日）用のHTMLスライド（18枚）。

`index.html` 1ファイルで動きます。ブラウザで直接開くか、`python3 -m http.server 8000` で配信してください。フォントの読み込みにはネット接続を使います。

## 構成

- 1〜11枚目：AIの説明と活用の考え方。
- 12枚目：説明資料 → HTMLスライド → 小さな仕事を任せる、という今日の流れ。
- 13〜18枚目：業務を選ぶ／準備と確認／聞かれて答える／5枚のスライドにする／Claude Codeに小さな仕事を任せる／締め。

実習の依頼文は税理士事務所版の3本です。各4行の全文を表示し、コピーする内容も表示本文から取得します。資料の名前は「新人向けの説明資料」、保存先はデスクトップです。成果を見せ合う時間や10人分の統合実演は入れていません。

最初の約90分で説明資料とスライド、残りの約30分で仕事を任せて結果を確認します。説明資料をClaudeのチャットへ渡すときは.mdファイルを添付し、Claude Codeへ渡すときはデスクトップを作業フォルダにして@からファイルを選びます。

顧問先の実際の情報は使いません。AIは下書き・チェック表・整理までで、人が最後に確認します。Artifactを共有する場合は社内限定にします。

## 操作

クリック／→で進む、←で戻る、数字キーでページへ移動、Gで一覧、Cで実習の依頼文をコピー、Aで自動再生、?で操作一覧。13枚目以降は1ページ内の段階表示がなく、開いた時点で全文を確認できます。
