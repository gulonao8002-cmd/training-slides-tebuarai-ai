# 手足のついたAI — 第2回AI研修スライド

税理士法人ファインブレーン 第2回AI研修（2026年10月7日）用のHTMLスライド（27枚）。

`index.html` をブラウザで直接開くか、ローカルサーバーで配信してください。フォントの読み込みにはネット接続を使います。

## 構成

- 1〜11枚目：AIの説明と活用の考え方。
- 12枚目：事務所の一番の資産は皆さんの頭の中にある、という実践への導入。
- 13枚目：実践の目次。1.設定する／2.自分の業務を言語化する／3-i.スライドにする／3-ii.実際の業務を任せる。
- 14枚目：クロコの準備。左上のCodeタブと、Windowsでデスクトップを選ぶ場所を、簡略化した画面例で示します。
- 15枚目：担当業務を想像する。複数思い浮かんだ場合は全部箇条書きにする。例は月次の記帳／通帳と記帳の照合／試算表のチェック。
- 16枚目：5〜7問程度の質問に答え、新人向けの説明資料をWordとMarkdownで作る。AIエージェントに任せられそうなものと無理そうなものも整理する。
- 17枚目：同じ会話で作った説明資料から、新人に伝わる5枚のHTMLスライドを作る。
- 18枚目（実践2：実際の業務を効率化してみる）：業務を思いつく人は自分の業務をクロコに依頼し、思いつかない人はダミーの通帳明細と普通預金元帳を照合する。
- 19枚目：もう一つの例。時間に余裕のある人や、より高度な例を体験したい人向け。ダウンロードしたZIP（月次資料と前回の面談メモ・ダミー）の移動と解凍もクロコに任せ、次回の経営面談用の5枚のHTMLスライド（確認したい変化・聞く質問・支援案のたたき台）を作る。

旧12枚目の「今日やること」は割愛しました。実践の目次以降ではClaude Codeを「クロコ」と呼びます。同じクロコのセッションで、説明資料・スライド作成・業務依頼またはファイル照合を続けます。画面の切り替えや説明資料の再添付は不要です。

依頼文はユーザー指定の本文（8行・5行・6行）をそのまま表示し、見出しを本文とは別の行にしています。コピー内容も表示本文から取得し、指定の改行を保ちます。資料の名前は「新人向けの説明資料」、保存先はデスクトップです。17枚目の練習ファイルもデスクトップに保存します。成果を見せ合う時間や10人分の統合実演は入れていません。

最初の約90分で説明資料とスライドを作り、残りの約30分で自分の業務を任せるか、練習用ファイルの照合を体験します。

## 文字サイズの基準

実践スライド（13〜19枚目）と参考情報（21〜27枚目）で、同じ役割の文字は同じ大きさにそろえています（舞台1920×1080pxでの値）。

- 見出し：64px（14〜19枚目、21〜27枚目）
- 題名（手順・カード・目次の項目）：32px
- 説明：24px
- 依頼文（クロコの入力欄の中）：27px。見出し行は24px
- 依頼カードの題名：19px、コピーボタン：18px
- ダウンロードボタン：24px、「選び方」などの帯の説明：24px

13枚目と20枚目の大きな見出し、14枚目の画面例の中の文字、図の注釈などは、この基準の対象外です。

## 操作

クリック／→で進む、←で戻る、数字キーでページへ移動、Gで一覧、Cで実践の依頼文をコピー、Aで自動再生、?で操作一覧。12枚目は「それを、今日かたちにします」が見えている状態から、1クリックで「それでは実際に体験に入りましょう」を追加表示します。13枚目以降は開いた時点で全文を確認できます。左側の番号は01〜27の通し番号です。

## 18・19枚目の依頼文の段階表示

18枚目のB（照合）と19枚目は、受講者に依頼文を自分で考えてもらうため、依頼文を3段階で見せます。右下の小さな「PW」欄に数字を入れて切り替えます（半角・全角どちらも可）。スライドごとに独立していて、開き直すと1に戻ります。

- 1（初期表示／空欄）：依頼文をぼかして隠し、「まずは、自分の言葉で依頼文を書いてみましょう」と表示。課題・素材・確認点は見えたままです。コピーはできません。
- 2：同じ行数の「骨組みのヒント」（黄色の枠＝自分の言葉で埋める所）。コピーはできません。
- 3：従来どおりの全文表示。コピーもできます。

見た目の位置は3段階とも同じです（行数・高さをそろえています）。PWは数字そのものなので、鍵ではなく進行用の切り替えです。18枚目のA（自分の業務）は対象外で、常に全文を表示します。

## 18枚目の照合体験

スライド上のダウンロードリンクから、研修用のダミーExcelファイルを取得できます。

- `assets/practice-data/通帳明細.xlsx`
- `assets/practice-data/普通預金元帳.xlsx`
- `assets/税理士事務所_AI依頼業務例.zip`（2ファイルをまとめたZIP）

MacとWindowsのどちらでもExcelで開ける標準のExcel（.xlsx）形式です。通帳にだけあるATM引出、金額が異なる電気料金、元帳に重複した家賃を含めています。答えはファイル内に記載せず、クロコの結果と原本を参加者が見比べる形式です。

## 19枚目の経営面談準備体験

18枚目の実践に続く「もう一つの例」です。スライド上のダウンロードリンクから、研修用のダミーデータ一式（ZIP）を取得できます。

- `assets/経営面談の準備_実習データ.zip`

依頼文の1行目で、クロコがダウンロードフォルダのZIPをデスクトップへ移動し、解凍します。ZIPを展開すると `経営面談の準備_実習データ/` フォルダに、次のファイルが入っています。

- `01_月次財務資料.xlsx`：月次損益計算書・月次貸借対照表（12か月）。
- `02_顧客別・案件別売上.xlsx`：月別・顧客別・案件別の売上と外注費。
- `03_売掛金年齢表.xlsx`：売掛金年齢表（2026年9月30日現在）と、顧客別の売掛金の推移。
- `04_資金予定表.xlsx`：今後3か月の資金予定と、入金が遅れた場合の試算。
- `05_前回面談メモ.md`：前回面談のメモ（背景のみ）。
- `README.md`：データの説明。

ZIPの名前もZIP内のフォルダ名・ファイル名も日本語です。WindowsとMacで文字化けしないよう、ZIPの名前はUnicodeの正規化形式（NFC）にそろえ、UTF-8であることを示すフラグを付けています。

会社・取引先・金額はすべて架空です。表はすべて標準の `.xlsx` で、同じ数字はファイルをまたいでも一致します（損益の売上高と売上明細、貸借の売掛金と年齢表、貸借の預金と資金予定の期首）。分析結果や答えはファイルに書いていません。クロコが数字を読み、確認したい変化・仮説・質問・支援案のたたき台を作り、人が確認して面談に使う、という体験です。
