# 手足のついたAI — 第2回AI研修スライド

税理士法人ファインブレーン 第2回AI研修（2026年10月7日）用のHTMLスライド（18枚）。

`index.html` をブラウザで直接開くか、ローカルサーバーで配信してください。フォントの読み込みにはネット接続を使います。

## 構成

- 1〜11枚目：AIの説明と活用の考え方。
- 12枚目：事務所の一番の資産は皆さんの頭の中にある、という実践への導入。
- 13枚目：実践の目次。1.設定する／2.自分の業務を言語化する／3-i.スライドにする／3-ii.実際にその業務をクロコに依頼する。
- 14枚目：クロコの準備。左上のCodeタブと、Windowsでデスクトップを選ぶ場所を、簡略化した画面例で示します。
- 15枚目：担当業務を想像する。複数思い浮かんだ場合は全て箇条書きにする。例は月次の記帳／通帳と記帳の照合／試算表のチェック。
- 16枚目：5〜7問程度の質問に答え、新人に対する説明資料をWord形式とmd形式で作る。AIエージェントに任せられそうなものと無理そうなものも整理する。
- 17枚目：同じ会話の説明資料から、見やすい5枚のHTMLスライドを作り、デスクトップに保存して開いてもらう。
- 18枚目：同じ会話でAIがどこまで業務をできるかを聞き、その上で仕事を任せる。不明点は質問してもらう。

旧12枚目の「今日やること」は割愛しました。実践の目次以降ではClaude Codeを「クロコ」と呼びます。同じクロコのセッションで、説明資料・スライド・実務作業を続けます。画面の切り替えや説明資料の再添付は不要です。

依頼文はユーザー指定の本文（5行・3行・2行）をそのまま表示し、コピー内容も表示本文から取得します。資料の名前は「新人に対する説明資料」、保存先はデスクトップです。成果を見せ合う時間や10人分の統合実演は入れていません。

最初の約90分で説明資料とスライド、残りの約30分で仕事を任せて結果を確認します。18枚目では通帳と記帳データの照合を例示します。

## 画面例

14枚目の画面例は、既存のスライドと同様にHTMLで簡略化した再現です。CodeをClaudeのすぐ左に配置し、Windowsのフォルダー選択画面を示します。スライド内の出典リンク・架空情報の注意書き・手順を並べた文章は削除しました。

出典：https://code.claude.com/docs/en/desktop-quickstart

## 操作

クリック／→で進む、←で戻る、数字キーでページへ移動、Gで一覧、Cで実践の依頼文をコピー、Aで自動再生、?で操作一覧。12枚目は「それを、今日かたちにします」が見えている状態から、1クリックで「それでは実際に体験に入りましょう」を追加表示します。13枚目以降は開いた時点で全文を確認できます。左側の番号は01〜18の通し番号です。

16〜18枚目の依頼文の右側は、確認項目ではなく取り組み方のメッセージです。16枚目は質問に答えながら少しずつ言語化すること、17枚目は作ったものへの追加の修正依頼、18枚目はAIを部下として使い最終チェックを自分で行うことを伝えます。
