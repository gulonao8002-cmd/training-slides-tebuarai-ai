# 手足のついたAI — 第2回AI研修スライド

税理士法人ファインブレーン 第2回AI研修（2026年10月7日）用のHTMLスライド（26枚）。

`index.html` をブラウザで直接開くか、ローカルサーバーで配信してください。フォントの読み込みにはネット接続を使います。

## 構成

- 1〜11枚目：AIの説明と活用の考え方。
- 12枚目：事務所の一番の資産は皆さんの頭の中にある、という実践への導入。
- 13枚目：実践の目次。1.設定する／2.自分の業務を言語化する／3-i.スライドにする／3-ii.ファイルを照合する。
- 14枚目：クロコの準備。左上のCodeタブと、Windowsでデスクトップを選ぶ場所を、簡略化した画面例で示します。
- 15枚目：担当業務を想像する。複数思い浮かんだ場合は全て箇条書きにする。例は月次の記帳／通帳と記帳の照合／試算表のチェック。
- 16枚目：5〜7問程度の質問に答え、新人に対する説明資料をWord形式とmd形式で作る。AIエージェントに任せられそうなものと無理そうなものも整理する。
- 17枚目：同じ会話で作った説明資料から、新人に伝わる5枚のHTMLスライドを作る。
- 18枚目：業務を思いつく人は自分の業務をクロコに依頼し、思いつかない人はダミーの通帳明細と普通預金元帳を照合する。

旧12枚目の「今日やること」は割愛しました。実践の目次以降ではClaude Codeを「クロコ」と呼びます。同じクロコのセッションで、説明資料・スライド作成・業務依頼またはファイル照合を続けます。画面の切り替えや説明資料の再添付は不要です。

依頼文はユーザー指定の本文（8行・5行・6行）をそのまま表示し、見出しを本文とは別の行にしています。コピー内容も表示本文から取得し、指定の改行を保ちます。資料の名前は「新人に対する説明資料」、保存先はデスクトップです。17枚目の練習ファイルもデスクトップに保存します。成果を見せ合う時間や10人分の統合実演は入れていません。

最初の約90分で説明資料とスライドを作り、残りの約30分で自分の業務を任せるか、例のファイル照合を体験します。

## 画面例

14枚目の画面例は、既存のスライドと同様にHTMLで簡略化した再現です。CodeをClaudeのすぐ左に配置し、Windowsのフォルダー選択画面を示します。スライド内の出典リンク・架空情報の注意書き・手順を並べた文章は削除しました。

出典：https://code.claude.com/docs/en/desktop-quickstart

## 操作

クリック／→で進む、←で戻る、数字キーでページへ移動、Gで一覧、Cで実践の依頼文をコピー、Aで自動再生、?で操作一覧。12枚目は「それを、今日かたちにします」が見えている状態から、1クリックで「それでは実際に体験に入りましょう」を追加表示します。13枚目以降は開いた時点で全文を確認できます。左側の番号は01〜26の通し番号です。

## 参考情報（19〜26枚目）

19枚目は「AIを使うコツと基礎知識」の扉です。背景とカードの体裁は維持し、20〜23枚目を使い方のコツ、24〜26枚目を基礎知識として整理しています。

- 20枚目：依頼→作業→確認→修正の流れと、途中の質問への返答例。
- 21枚目：目的・材料・完成形・進め方の4要素と、色と位置で対応させた依頼文。
- 22枚目：質問・途中報告・保存して開く、を取り入れた依頼文。
- 23枚目：どこを・どう変えるかを伝える修正依頼と、図のイメージ。
- 24枚目：原本を残す・操作を読む・結果を開く、の3場面を図示。
- 25枚目：AIに任せる作業と、自分が確認する内容を3行で対応。
- 26枚目：用語を普段の言葉に置き換えて説明。コンテキストとトークンを区別。

21〜23枚目の例文はコピーできます。見出しや図の注釈は、本文と区別して表示します。19枚目以降も動きなしで全文を表示します。

## 実践中のメッセージ

16〜18枚目の依頼文の右側は、確認項目ではなく取り組み方のメッセージです。16枚目は質問に答えながら少しずつ言語化すること、17枚目は作ったものへの追加の修正依頼、18枚目はAIを部下として使い最終チェックを自分で行うことを伝えます。

## GitHub Pages

静的配信用の `index.html` と `.nojekyll` をリポジトリのルートに置いています。依存パッケージのインストールやビルドは不要です。

Pagesを設定できる所有者・管理者が、Settings → Pages → Deploy from a branch を選び、`main` / `/ (root)` を指定して保存してください。
非公開リポジトリでは所有者のGitHub Pro等の対応プランが必要です。GitHub Freeで公開する場合は、ソースと履歴の公開可否を所有者が判断してください。
GitHub Pagesは `main` / `/ (root)` で公開中です。

## 17枚目の照合体験

スライド上のダウンロードリンクから、研修用のダミーExcelファイルを取得できます。

- `assets/practice-data/通帳明細.xlsx`
- `assets/practice-data/普通預金元帳.xlsx`
- `assets/税理士事務所_AI依頼業務例.zip`（2ファイルをまとめたZIP）

MacとWindowsのどちらでもExcelで開ける標準のExcel（.xlsx）形式です。通帳にだけあるATM引出、金額が異なる電気料金、元帳に重複した家賃を含めています。答えはファイル内に記載せず、クロコの結果と原本を参加者が見比べる形式です。
