# 手足のついたAI — 第2回AI研修スライド

税理士法人ファインブレーン 第2回AI研修（2026年10月7日）用のHTMLスライド（18枚）。

`index.html` をブラウザで直接開くか、ローカルサーバーで配信してください。フォントの読み込みにはネット接続を使います。練習データを使う場合は `practice-data.zip` を同じ場所に置いてください。

## 構成

- 1〜11枚目：AIの説明と活用の考え方。
- 12枚目：事務所の一番の資産は皆さんの頭の中にある、という実践への導入。
- 13枚目：実践の目次。1.設定する／2.自分の業務を言語化する／3-i.スライドにする／3-ii.実際にその業務をクロコに依頼する。
- 14枚目：クロコの準備。Code → Local → Select folder → デスクトップ → 開くを、簡略化した画面例で示します。
- 15枚目：業務を一つ選び、メモする。例は月次の記帳／通帳と記帳の照合／試算表のチェック。
- 16枚目：AIの質問に業務内容を答え、新人に対する説明資料を作る。
- 17枚目：同じ会話の説明資料から、5枚のHTMLスライドを作り、デスクトップに保存する。
- 18枚目：同じ会話で業務の一部を任せ、結果と根拠を確認する。

旧12枚目の「今日やること」は割愛しました。実践の目次以降ではClaude Codeを「クロコ」と呼びます。同じクロコのセッションで、説明資料・スライド・実務作業を続けます。画面の切り替えや説明資料の再添付は不要です。

依頼文は4行・3行・4行の全文を表示し、コピー内容も表示本文から取得します。資料の名前は「新人に対する説明資料」、保存先はデスクトップです。成果を見せ合う時間や10人分の統合実演は入れていません。

最初の約90分で説明資料とスライド、残りの約30分で仕事を任せて結果を確認します。顧問先の実際の情報は使いません。仕訳案の作成・通帳と記帳の照合などをAIに任せ、人が根拠と結果を確認します。仕訳の確定・申告・送信・外部への登録は行いません。

## 画面例

14枚目の画面例は、既存のスライドと同様にHTMLで簡略化した再現です。LocalとSelect folderの手順は公式ガイドを確認しています。実際の画面やOSの言語によって表示名・配置は異なります。

## 練習データ

18枚目の「練習データを保存」で `practice-data.zip` を保存します。通帳・記帳CSVは架空データです。ZIPを開き、2つのCSVをデスクトップへ置いて、@から同じ会話に渡してください。既に作成した説明資料は再添付しません。

## 操作

クリック／→で進む、←で戻る、数字キーでページへ移動、Gで一覧、Cで実践の依頼文をコピー、Aで自動再生、?で操作一覧。12枚目は「それを、今日かたちにします」が見えている状態から、1クリックで「それでは実際に体験に入りましょう」を追加表示します。13枚目以降は開いた時点で全文を確認できます。左側の番号は01〜18の通し番号です。
